# Folio — открытый просмотрщик документов для Android

Kotlin + Jetpack Compose. Разработка: VS Code + GitHub. Лицензия **AGPL-3.0-or-later** (требование MuPDF).

## Что умеет (v0.2)

| Область | Статус |
|---|---|
| Форматы: PDF, EPUB, MOBI, FB2, CBZ, XPS, SVG, TXT, HTML, изображения | MuPDF |
| DOCX / XLSX / PPTX / ODF | MuPDF ≥ 1.25 |
| CBR | junrar → CBZ |
| Просмотр | по страницам (свайп) или лента; зум щипком в точке жеста, двойной тап, чёткий зум без потолка (рендер только видимого фрагмента) |
| Аннотации (не зависят от текстового слоя) | перо с давлением, маркер, подчёркивание, ластик (в том числе частичный), заметки |
| Аннотации по тексту (при наличии текстового слоя) | «Выдел. текста», «Подч. текста» — по строкам текста |
| Страницы PDF | поворот, удаление, пустая страница, вставка страниц из другого PDF; исходник не меняется |
| Формы PDF | текстовые поля, флажки, списки; подпись — пером |
| Экспорт | PDF со стандартными Ink / Highlight / Underline / Text аннотациями и правками страниц |
| Миниатюры | скрываемая панель, низкий приоритет рендера |
| Библиотека | вкладки «Недавние» и «Библиотека», обложки (первая страница), фильтры, сортировка, поиск, избранное |
| Поиск | постраничный, отменяемый, результаты появляются по мере нахождения |

## Не сделано

- **DjVu** — нужен NDK-модуль на djvulibre (GPL, совместима с AGPL). Интерфейс `DocumentEngine` для него готов.
- **Привязка аннотаций в EPUB/FB2 по CFI.** Сейчас они привязаны к параметрам вёрстки (ширина × высота × шрифт) и скрываются при смене шрифта или ориентации.
- Редактирование текста внутри PDF.

## Сборка

```bash
./gradlew :app:assembleDebug
./gradlew :app:installDebug          # телефон по USB
./gradlew :app:testDebugUnitTest     # юнит-тесты геометрии аннотаций
```
Нужны JDK 17 и Android SDK (platform 35). Gradle wrapper уже в репозитории.
CI (`.github/workflows/build.yml`) собирает APK на каждый push; тесты идут отдельным шагом и сборку не блокируют.

### Подпись релиза
Добавьте секреты репозитория `KEYSTORE_BASE64` (keystore в base64), `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.
Без них release-APK подписывается debug-ключом. R8 для release выключен намеренно (надёжность важнее размера).

## Структура

- `engine/` — `DocumentEngine`, `MuPdfEngine`, `SafeEngine` (мьютекс, кэш, приоритеты), `PdfEditor`, `PdfExporter`, `ComicConverter`
- `data/` — Room, открытие документов (SAF → кэш), `ScanWorker`, `CoverMaker`
- `annotations/` — модель, геометрия (стирание, поворот), `PageOverlay`
- `ui/` — библиотека, читалка, ViewModel'и

## Лицензии
