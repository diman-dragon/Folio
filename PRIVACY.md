# Политика конфиденциальности / Privacy Policy

**Folio** — открытая читалка документов (AGPL-3.0). Разработчик и оператор / Developer: **DataLaw**. Последнее обновление: 2026-10.

## По-русски
- Приложение **работает полностью офлайн**. У него нет разрешения на доступ в интернет, нет аналитики, рекламы, трекеров и учётных записей.
- **Никакие данные не собираются и не передаются** разработчику или третьим лицам.
- Документы открываются через системный выбор файлов (Storage Access Framework): приложение получает доступ только к файлам и папкам, которые вы выбрали сами. Содержимое документов обрабатывается на устройстве.
- На устройстве хранятся: список книг и обложки, прогресс чтения, ваши аннотации (рисунки, выделения, заметки), настройки, временные копии открытых документов (кэш) и рабочие копии PDF, если вы правили страницы. Очистить кэш можно в «Настройки → Данные». Удаление приложения удаляет всё.
- Буфер обмена используется только когда вы сами выбираете «Копирование текста».
- Резервное копирование Android (если включено в системе) может сохранять базу аннотаций и настройки; документы и обложки в копию не попадают.
- Исходный код открыт: вы можете проверить всё сказанное выше.

Вопросы: создайте issue в репозитории проекта.

## In English
- The app works **fully offline**: no internet permission, no analytics, ads, trackers or accounts.
- **No data is collected or sent** to the developer or any third party.
- Documents are opened through the system file picker (Storage Access Framework); the app can only read files and folders you pick. Documents are processed on-device.
- Stored on the device: library index and covers, reading progress, your annotations, settings, temporary document copies (cache) and working PDF copies if you edited pages. Cache can be cleared in Settings → Data. Uninstalling removes everything.
- The clipboard is written only when you explicitly use "Copy text".
- Android backup (if enabled) may include the annotation database and settings; documents and covers are excluded.
- The source code is open, so all of the above can be verified.

Questions: open an issue in the project repository.
