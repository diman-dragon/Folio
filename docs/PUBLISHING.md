# Публикация Folio

## Бренд DataLaw
- Название разработчика в Play Console и F-Droid: **DataLaw**. В приложении знак и название — Настройки → О приложении (`ic_datalaw.xml`, `Brand.kt`).
- Исходники знака: `docs/brand/datalaw-mark.svg` (вектор) и `docs/brand/datalaw-logo-original.png` (оригинал).
- Графика для магазина содержит знак DataLaw в левом нижнем углу. Название приложения и значок Folio не менялись.
- **Важно:** `applicationId` (`app.folio`) нельзя изменить после первой публикации в Google Play. Если хотите идентификатор в домене бренда (например, `com.datalaw.folio`), решите это ДО первой загрузки и поменяйте `namespace`/`applicationId` в `app/build.gradle.kts`.

## 0. Что уже готово
- `targetSdk 36` / `compileSdk 36` — Google Play с 31.08.2026 принимает обновления только с API 36.
- Toolchain на уровне Capacitor 8 (Android): AGP 8.13.0, Gradle 8.14.3, JDK 21 в CI, Kotlin 2.0.21.
- Подпись релиза из секретов GitHub, сборка APK + AAB по тегу, контрольные суммы, проверка 16 КБ.
- Тексты, иконка 512×512 и графика 1024×500 для магазина: `fastlane/metadata/android/{ru-RU,en-US}`.
- Политика конфиденциальности: `PRIVACY.md`. В приложении есть ссылки на исходный код и политику (Настройки → О приложении).

## 1. Ключ подписи (один раз)
```bash
keytool -genkeypair -v -keystore folio-release.jks -alias folio -keyalg RSA -keysize 4096 -validity 10000
base64 -w0 folio-release.jks      # на macOS: base64 -i folio-release.jks
```
В репозитории: Settings → Secrets and variables → Actions → New repository secret:
`KEYSTORE_BASE64` (вывод base64), `KEYSTORE_PASSWORD`, `KEY_ALIAS` (`folio`), `KEY_PASSWORD`.
**Храните keystore в надёжном месте вне репозитория.** В Play Console включите Play App Signing: этот ключ станет «ключом загрузки» и его можно будет заменить.

## 2. Выпуск версии
```bash
git tag v1.1.0
git push origin v1.1.0
```
Workflow `release` соберёт подписанные `folio-v1.1.0.apk` и `.aab`, проверит 16 КБ и создаст GitHub Release с файлами и `SHA256SUMS.txt`.
`versionCode` = 110 + номер запуска, `versionName` берётся из тега.

## 3. Google Play Console
1. Создайте приложение (язык по умолчанию — русский), загрузите `.aab` в Internal testing, затем в Production.
2. Карточка магазина: скопируйте тексты из `fastlane/metadata/android/ru-RU` и `en-US`; значок — `images/icon.png`; графика — `images/featureGraphic.png`.
3. **Скриншоты телефона (минимум 2) сделайте сами** с реального устройства или эмулятора: библиотека, чтение с аннотациями, панель пера, заметка.
4. Политика конфиденциальности: ссылка на `PRIVACY.md` в вашем репозитории (`https://github.com/<вы>/<репозиторий>/blob/main/PRIVACY.md`).
5. Data safety: «Приложение не собирает и не передаёт данные». Разрешений приложение не запрашивает, доступ в интернет отсутствует.
6. Анкета возрастного рейтинга: нет насилия, нет азартных игр, нет пользовательского контента между людьми.
7. Реклама: нет. Приложение для детей: нет. Доступ к приложению: без ограничений.

## 4. Проверки перед отправкой
- В CI шаг «16 KB page-size check» должен быть зелёным (в `release` он блокирующий).
  Нативная библиотека MuPDF приходит готовой из `maven.ghostscript.com`; **если проверка красная** — возьмите более новую версию `mupdfVersion` в `app/build.gradle.kts` или соберите AAR из исходников с NDK r28+ (выравнивание 16 КБ). Google Play перестанет принимать загрузки без 16 КБ с 1 февраля 2027.
- Прогон на эмуляторе Android 16 (API 36) и на образе с 16 КБ страницами: открыть PDF/EPUB, нарисовать штрих, выделить слово, поставить заметку, повернуть экран, проверить жест «назад».
- `./gradlew :app:testDebugUnitTest` и `./gradlew lint`.

## 5. Лицензия (AGPL-3.0)
- Репозиторий должен оставаться публичным, файл `LICENSE` — в корне. Ссылка на исходный код встроена в приложение и подставляется автоматически из `GITHUB_REPOSITORY` при сборке в Actions (локально: `-PsourceUrl=https://github.com/<вы>/<репо>`).
- Изменённый код, распространяемый пользователям (в том числе через Google Play), должен быть доступен под AGPL.
- Если нужен закрытый код — потребуется коммерческая лицензия MuPDF у Artifex.

## 6. F-Droid (по желанию)
Структура `fastlane/metadata/android` уже соответствует требованиям. Отправьте merge request в `fdroiddata` с метаданными сборки; зависимости приложения — только открытые.

## 7. Известные ограничения версии 1.0
- Интерфейс только на русском.
- Нет DjVu; аннотации в EPUB/FB2 привязаны к параметрам вёрстки (ширина × высота × шрифт).
- Совместимость 16 КБ у нативной библиотеки MuPDF не проверена автором — см. п. 4.

## Совместимость с Capacitor 8
Проект — нативное приложение (Kotlin + Compose), а не Capacitor-приложение. Android-база приведена к минимумам Capacitor 8, поэтому модуль можно подключать рядом с проектом на Capacitor 8 без конфликта версий инструментов:

| | Capacitor 8 | Folio |
|---|---|---|
| compileSdk / targetSdk | 36 | 36 |
| AGP | 8.13.0 | 8.13.0 |
| Gradle | 8.14.3 | 8.14.3 |
| JDK (CI) | 21 | 21 |
| minSdk | 24 | 26 (адаптивная иконка и API нативной части) |
| Kotlin | 2.2.20 | 2.0.21 (повышение требует Room 2.7+ и новый KSP) |
